# 设计

目录枚举、内容指纹、差异计划和执行分离。快速模式读取元数据，按内容复用时只对候选计算指纹；缓存模式复用有效指纹，完整模式重读全部内容。同路径的相同字节大小在 BuildItems 中统一视为相同。

执行选项 RecordsInChild 决定操作计划、日志和备份根目录。默认使用子文件夹的程序专属目录；关闭时使用本机应用数据 MISee/Records，检查目录不与任一资料树重叠及路径联接风险，并检查本机备份空间。两种方式共用备份、冲突保存、取消和异常记录逻辑，母本保持只读。索引缓存仍独立保存在本机。

执行逐项检查源和目标大小、时间、路径及新增目标占用。写入校验开启时，复制中计算源指纹并读回验证，临时文件验证后才覆盖目标。完整复核用于检测计划生成后发生的变化。

FileSystemWatcher 追踪在线变更；通知失效、缓冲溢出或根目录身份变化时重建元数据。定期元数据检查与手动内容扫描提供后备。NTFS 日志仅只读查询；日志不可用或变化时安全退回扫描，exFAT 不依赖 USN。
