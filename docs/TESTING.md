# 测试与验证范围

运行 `./scripts/test.ps1`，七组测试会在 `artifacts/test-results/` 创建各自的独立实验资料，报告失败时脚本以错误退出。不会自动操作外部用户资料。

| 测试组 | 断言数 | 范围 |
| --- | ---: | --- |
| self | 17 | 基础比对和路径冲突规则 |
| performance | 72 | 与基准匹配结果对照、扫描、中断、规模计算 |
| integration | 31 | 实际更新、备份、取消清理和空间检查 |
| option | 11 | 完整复核开关及逐项保护 |
| smart | 35 | 指纹、深层变更、改名删除、缓存异常和局部更新 |
| ui | 19 | 按钮流程、筛选勾选、执行与中断 |
| layout | 14 | 字号行高、按钮边界、紧凑窗口、任务信息 |
| 合计 | **199** | 自建实验资料 |

原始 CLI 入口为 `--self-test`、`--performance-test`、`--integration-test`、`--option-test`、`--smart-test`、`--ui-test`、`--layout-test`，后接报告输出文件完整路径。

## 性能验证

智能索引实验包含母子共 6,002 个文件，其中有两份 32 MiB 文件。完整方式读取至少 64 MiB，快速方式内容读取为零，通知稳定后再次比对不重新检查文件元数据。具体耗时受硬件和系统缓存影响，不将小样本秒数外推为 TB 级处理时间。

监控初始化可能收到额外通知并触发安全回退。测试先等待初始状态收敛，再检查稳定状态下的零扫描；不会因追求零扫描而关闭异常回退。深层文件变化测试包含祖先目录时间不变的情形。

## 限制

本地常规与紧凑窗口已检查；没有切换实际系统到 125%／150% 缩放。CI 状态应以 GitHub Actions 最新运行结果为准。
