# 使用指南

## 安装和启动

运行打包文件中的 `咪看看（MISee）.exe`，并保留同目录 DLL、deps.json、runtimeconfig.json。框架依赖版需要 .NET 10 Windows Desktop Runtime x64。

## 日常局部更新

选择两个独立的文件夹，母本作为内容标准、子本作为更新目标。两者不能相同或互相包含。默认独有资料“原处保留”，不删除整个子文件夹重拷。

点击“开始比对”，可按操作或关键词筛选结果，再勾选需要执行的项目。筛选只影响显示，执行会处理原计划中的全部勾选项；按钮和汇总显示总勾选数。确认清单后点击“执行更新”。

## 比对方式与选项

| 方式 | 内容读取范围 |
| --- | --- |
| 快速 | 依赖路径、大小、时间和有效已有指纹；仅按需读取内容复用候选 |
| 缓存内容 | 对无有效指纹或属性变化的文件计算 SHA-256 |
| 完整内容 | 重新列举目录并读取全部内容，忽略指纹缓存 |

快速模式不保证发现没有有效指纹的同大小、同时间内容变化。缓存内容模式也依赖属性及在线通知判断缓存是否仍有效。主动检查静默损坏时选择完整内容方式。

“高级设置”保留指纹缓存、在线变更索引、内容复用、执行前整库复核及实际写入校验。执行前整库复核默认关闭，TB 级资料开启后可能等待较久；默认开启的写入校验只检查本次操作涉及的内容。

缓存存放在 `%LOCALAPPDATA%\MISee\Index-v1`。缓存路径处于所选资料树内时禁写。重建本机索引仅清理程序自身缓存。

## 更新规则

- 母本只读。内容一致时保留现有资料。
- 母版本较新时更新，覆盖前备份原子版本。
- 子版本较新时保留子版本。
- 同日期内容冲突保留子版本，并把母版本另存到执行记录。
- 缺失目标可按内容复用子本独有文件，否则从母本复制。
- 独有资料可原处保留、归档到额外资料或删除到回收站，默认原处保留。

快速方式中，大小和时间不同时也可能存在内容相同的文件；需要按实际内容辨别时选择缓存内容或完整内容方式。

## 进度、中断与记录

底部任务区显示阶段、百分比、预计时间和读写量。总量尚不明确时显示统计中；实际磁盘速度和文件数量会影响预计时间。

点击“中断”会停止后续工作，等待当前系统调用返回。普通读取和复制按数据块检查取消，复制半成品会清理；已完成操作及备份保留，不自动回滚。再次比对后可继续处理剩余差异。

记录保存在子本 `.MISee记录/本次编号`。覆盖前版本位于 `更新前备份`，冲突母版本位于 `同日期冲突_母版本`。错误会给出具体文件和记录位置。记录和索引不应提交到公开仓库。

符号链接、联接点及文件／目录同名冲突会拒绝处理。云端占位资料应先完整下载。本地目标磁盘在执行前检查空间，计入备份和临时覆盖所需容量。处理期间避免另一程序同时更改相关文件。
