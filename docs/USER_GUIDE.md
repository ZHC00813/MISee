# 使用指南 v0.9

选择两个互不包含的文件夹。母文件夹只读，子文件夹接收更新。默认快速扫描、独有资料原处保留、执行前跳过整库复核、本次写入校验开启。

## 文件判定与选择

同相对路径、同文件名、同字节大小视为相同，不要求修改时间或 SHA-256 一致。快速模式避免整库内容读取；缓存和完整模式仍采集指纹，用于内容复用及操作保护，但不会把同大小的同路径文件列为更新。

“全选”“全不选”“反选”只修改当前筛选显示项目的勾选。搜索或筛选外的项目不变。清除搜索并选“全部操作”后可对所有项目操作。“保留”项目不会执行写入，即使被勾选。

## 记录位置

高级设置中“在子文件夹内保存记录和备份”默认勾选：使用子目录中的 .MISee记录/本次编号。

取消勾选：使用 %LOCALAPPDATA%/MISee/Records/本次编号。日志、操作计划、更新前备份及冲突母版本均转存这里，不在子文件夹创建新的 .MISee记录。关闭不会删除已有记录。完成或中断后，“打开记录”打开本次实际位置。本机磁盘必须有空间容纳备份；本机记录目录与资料目录重叠时拒绝执行。

记录选项只决定新记录的位置，不禁用备份保护。“移到额外资料”仍在子文件夹创建额外资料归档，这是独有资料处理方式，与记录选项独立。

## 保护与限制

覆盖前备份旧版本，复制到临时文件并校验后替换；支持安全中断并清理半成品。已完成操作不自动回滚。运行时不要同时改动待处理资料。

同大小规则无法发现内容不同但大小相同的同路径文件。更新前完整复核可检测比对后文件发生的变化，仍遵守同大小视为相同的初始判定规则。索引按大小、时间、通知和指纹维护；目录时间不能代表后代内容，exFAT 重开后通常需重新枚举元数据。
